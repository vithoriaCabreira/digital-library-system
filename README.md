# 📚 Digital Library System

A Digital Library Management System developed in **C** as part of my Software Engineering and Embedded Systems learning journey.

This project is being built following software engineering best practices, focusing not only on programming in C but also on software architecture, documentation, version control, and project organization.

---

## 🎯 Project Goals

This project aims to strengthen my knowledge of:

- C Programming
- Modular Programming
- Data Structures
- File Handling
- Software Architecture
- Software Engineering Fundamentals
- Git & GitHub Workflow
- Documentation
- Clean Code
- Project Organization

Although this is not an embedded systems project, it serves as the foundation for future firmware and embedded software development projects.

---

## ✨ Planned Features

### 📖 Book Management

- Register books
- List books
- Search books
- Update book information
- Remove books

### 👤 User Management

- Register users
- List users
- Search users
- Update user information
- Remove users

### 📚 Loan Management

- Borrow books
- Return books
- List active loans
- Check book availability

### 💾 Data Persistence

- Save data to binary files
- Load data automatically when the application starts
